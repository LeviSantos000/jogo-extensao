# Jogo do Projeto de Extensão
Um jogo web educativo com HTML, CSS e JavaScript. Feito como projeto de extensão da faculdade com o objetivo de conscientizar e educar crianças sobre assuntos relacionados a área da tecnologia.  

**🔗Acesse o jogo pelo o GitHub Pages:** [Clique aqui para jogar](https://levisantos000.github.io/jogo-extensao/)
## Como Jogar?
* Clique na imagem do gabinete para aparecer as perguntas.
* Escolha a alternativa correta para ganhar 100 pontos.
* As respostas incorretas farão você perder 50 pontos.
* Ao final do tempo você receberá sua pontuação.

## Tecnologias
* HTML5
* CSS3
* JavaScript (ES6)

## Como Executar o Projeto Localmente?
1. Clone o repositório
```bash
git clone https://github.com/LeviSantos000/jogo-extensao.git
cd jogo-extensao
```
2. Abra o arquivo index.html

**Abra o arquivo `index.html` no seu navegador**.
